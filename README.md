# Binary Search Visualizer

A simple and interactive web application that visualizes the binary search algorithm. Users can add elements to an array, and then input a target value to see how the algorithm searches for that value step by step.

## Features
- Add elements to the array dynamically.
- Visualize the binary search process.
- Highlight the current range being searched.
- Indicate when the target is found or not found.

## Technologies Used
- HTML
- CSS
- JavaScript

## Usage
Adding Elements: Enter a number in the "Enter array element" input field and click "Add Element". The elements will be sorted automatically.
Starting the Search: Enter a target value in the "Enter target value" input field and click "Start Search" to visualize the search process.
Message Display: The message box will display whether the target was found or not.

## How It Works
The application maintains an array of numbers, which can be modified by the user.
When the user starts the search, the binarySearchVisualizer function executes, highlighting the current mid-point and search range.
The application uses asynchronous delays to allow users to see each step of the binary search process.
Tiles representing the array elements change color based on their state (e.g., mid-point, range, found).
